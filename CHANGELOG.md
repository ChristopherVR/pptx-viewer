### Added

- `CHANGELOG.md` following the Keep a Changelog format.
- `author`, `repository`, `homepage`, and `bugs` metadata to all published `package.json` files.
- `LICENSE` and `NOTICE` files added to each package's `files` array so they are included in npm tarballs.
