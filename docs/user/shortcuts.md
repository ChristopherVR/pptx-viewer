# Keyboard Shortcuts

These are the keyboard shortcuts built into the viewer/editor. On macOS, use **Cmd** wherever **Ctrl** is listed.

::: info Shortcuts are context-aware
Which shortcuts are active depends on the mode you're in and what you're doing. Editing shortcuts work in **edit mode** only, and are suppressed while you're typing in a text box, editing a table cell, or using a drawing tool (so the keys go to the text instead). Presentation shortcuts work only during a slideshow.
:::

## Editing

Available in edit mode, when you are not typing into an element.

| Action                                           | Shortcut                             |
| ------------------------------------------------ | ------------------------------------ |
| Undo                                             | **Ctrl + Z**                         |
| Redo                                             | **Ctrl + Shift + Z** or **Ctrl + Y** |
| Copy selected element                            | **Ctrl + C**                         |
| Cut selected element                             | **Ctrl + X**                         |
| Paste element                                    | **Ctrl + V**                         |
| Duplicate selected element                       | **Ctrl + D**                         |
| Delete selected element                          | **Delete** or **Backspace**          |
| Select all elements                              | **Ctrl + A**                         |
| Nudge selected element                           | **Arrow keys**                       |
| Nudge selected element (larger step)             | **Shift + Arrow keys**               |
| Commit inline text edit                          | **Ctrl + Enter**                     |
| Cancel inline text edit / close menus / deselect | **Escape**                           |

## Navigation

| Action                                       | Shortcut        |
| -------------------------------------------- | --------------- |
| Previous slide (edit mode, nothing selected) | **Left Arrow**  |
| Next slide (edit mode, nothing selected)     | **Right Arrow** |

::: tip
In edit mode the arrow keys do double duty: with an element selected they **nudge** it; with nothing selected they **change slides**.
:::

## View

| Action                   | Shortcut               |
| ------------------------ | ---------------------- |
| Zoom the canvas in / out | **Ctrl + Mouse wheel** |

Zoom in, zoom out, fit, and reset are also available as buttons in the status bar and **View** toolbar tab.

## Presentation (slideshow)

Available only while a fullscreen slideshow is running.

| Action                              | Shortcut                                        |
| ----------------------------------- | ----------------------------------------------- |
| Next slide / next animation         | **Right Arrow**, **Page Down**, or **Spacebar** |
| Previous slide                      | **Left Arrow** or **Page Up**                   |
| Exit the slideshow                  | **Escape**                                      |
| Toggle laser pointer                | **L**                                           |
| Toggle pen                          | **P**                                           |
| Toggle eraser                       | **E**                                           |
| Toggle presenter view (notes/timer) | **N**                                           |
| Show / hide the slideshow toolbar   | **Ctrl + M**                                    |

See [Presenting](/user/presenting) for how the annotation tools and presenter view work.
