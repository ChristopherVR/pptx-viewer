# Editar diapositivas

::: warning La edicion debe estar habilitada
La edicion solo esta disponible cuando la aplicacion esta configurada con el modo de edicion activado (el desarrollador establece `canEdit`). Si la barra de herramientas solo muestra opciones de visualizacion, esta en modo de solo lectura.
:::

## Seleccionar y mover elementos

Haga clic en cualquier elemento de la diapositiva para seleccionarlo. Un elemento seleccionado muestra controladores (pequenos cuadrados en las esquinas y en el centro de los bordes).

- **Mover** - arrastre el elemento seleccionado a una nueva posicion.
- **Redimensionar** - arrastre un controlador de esquina o borde para cambiar el tamano.
- **Rotar** - arrastre el controlador de rotacion (encima del elemento).
- **Multiseleccion** - mantenga **Mays** y haga clic para seleccionar varios elementos.

## Anadir elementos

Use la pestana **Insertar** de la barra de herramientas:

- **Texto** - inserte un cuadro de texto. Haga doble clic para editar el texto.
- **Formas** - dibuje rectangulos, elipses, flechas y mas de 187 formas predefinidas.
- **Imagen** - inserte desde un archivo local o URL.
- **Tabla** - inserte una tabla con un numero de filas y columnas elegido.
- **Grafico** - inserte un grafico; arrastre barras o puntos directamente en la diapositiva para cambiar valores, o edite los datos en el inspector.

## Formatear con el inspector

El panel **Inspector** (a la derecha) es contextual.

## Deshacer y rehacer

- **Deshacer** - **Ctrl/Cmd + Z**
- **Rehacer** - **Ctrl/Cmd + Mays + Z** o **Ctrl/Cmd + Y**

## Gestion de diapositivas

Trabaje con diapositivas desde el **panel de diapositivas** o el menu contextual:

- **Anadir diapositiva** - insertar una nueva diapositiva en blanco.
- **Duplicar** - copiar una diapositiva existente.
- **Eliminar** - eliminar la diapositiva seleccionada.
- **Reordenar** - arrastrar miniaturas en el panel.

## Buscar y reemplazar

Abra **Buscar y reemplazar** desde la pestana **Revisar** para buscar texto en **todas** las diapositivas a la vez.

## Comentarios

Use la pestana **Revisar** para anadir comentarios anclados a una diapositiva o elemento, responder, resolver o eliminar comentarios.
