# Atajos de teclado

Estos son los atajos de teclado integrados en el visualizador/editor. En macOS, use **Cmd** donde se indica **Ctrl**.

::: info Los atajos son sensibles al contexto
Los atajos activos dependen del modo en que se encuentre. Los atajos de edicion solo funcionan en **modo edicion** y se suprimen mientras escribe en un cuadro de texto.
:::

## Edicion

Disponible en modo edicion, cuando no esta escribiendo en un elemento.

| Accion                                          | Atajo                              |
| ----------------------------------------------- | ---------------------------------- |
| Deshacer                                        | **Ctrl + Z**                       |
| Rehacer                                         | **Ctrl + Mays + Z** o **Ctrl + Y** |
| Copiar elemento seleccionado                    | **Ctrl + C**                       |
| Cortar elemento seleccionado                    | **Ctrl + X**                       |
| Pegar elemento                                  | **Ctrl + V**                       |
| Duplicar elemento seleccionado                  | **Ctrl + D**                       |
| Eliminar elemento seleccionado                  | **Supr** o **Retroceso**           |
| Seleccionar todos los elementos                 | **Ctrl + A**                       |
| Mover ligeramente el elemento seleccionado      | **Teclas de flecha**               |
| Mover ampliamente el elemento seleccionado      | **Mays + Teclas de flecha**        |
| Confirmar edicion de texto en linea             | **Ctrl + Enter**                   |
| Cancelar edicion / cerrar menus / deseleccionar | **Escape**                         |

## Navegacion

| Accion                                                  | Atajo                |
| ------------------------------------------------------- | -------------------- |
| Diapositiva anterior (modo edicion, nada seleccionado)  | **Flecha izquierda** |
| Siguiente diapositiva (modo edicion, nada seleccionado) | **Flecha derecha**   |

## Presentacion

| Accion                                | Atajo                                              |
| ------------------------------------- | -------------------------------------------------- |
| Siguiente diapositiva / animacion     | Clic, **Flecha derecha**, **Av Pag** o **Espacio** |
| Diapositiva anterior                  | **Flecha izquierda** o **Re Pag**                  |
| Salir de la presentacion              | **Escape**                                         |
| Alternar vista del presentador        | **N**                                              |
| Activar puntero laser                 | **L**                                              |
| Activar boligrafo                     | **P**                                              |
| Activar borrador                      | **E**                                              |
| Mostrar/ocultar barra de diapositivas | **Ctrl + M**                                       |
