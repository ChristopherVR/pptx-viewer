# Visualizar presentaciones

Esta pagina cubre la lectura de una presentacion: abrir un archivo, moverse entre diapositivas, hacer zoom y ver las notas del presentador.

## Apertura de un archivo

Como se carga una presentacion depende de la aplicacion:

- Muchas aplicaciones cargan una presentacion automaticamente (por ejemplo, desde un enlace o un servidor).
- Las aplicaciones que le permiten elegir un archivo generalmente ofrecen una accion **Abrir** en la pestana **Archivo** de la barra de herramientas, o un area de arrastrar y soltar.

::: info Archivos cifrados
Si el archivo esta protegido por contrasena, la aplicacion muestra un dialogo de contrasena. Introduzca la contrasena para descifrar y abrir la presentacion.
:::

## Navegacion entre diapositivas

- **Panel de diapositivas** - Haga clic en cualquier miniatura de la izquierda para ir directamente a esa diapositiva.
- **Teclas de flecha** - Con nada seleccionado en el lienzo, presione **Flecha izquierda** / **Flecha derecha** para ir a la diapositiva anterior / siguiente.

::: tip Diapositivas ocultas
Las diapositivas marcadas como ocultas aparecen atenuadas en el panel y se omiten durante una presentacion, pero aun puede verlas y editarlas.
:::

## Zoom y ajuste

Use los controles de zoom en la **barra de estado** (o la pestana de barra de herramientas **Vista**):

- **Acercar** - aumente el nivel de zoom para ver los detalles.
- **Alejar** - disminuya para ver mas de la diapositiva.
- **Ajustar** - ajuste para que toda la diapositiva quepa en la ventana.

## El clasificador de diapositivas

Accesible desde la pestana **Vista** o la barra de estado. Muestra todas las diapositivas como una cuadricula de miniaturas, facilitando la reorganizacion.

## Notas del presentador

Haga clic en el **panel de notas** debajo del lienzo para leer o editar las notas del presentador de la diapositiva actual.
