# Guia de usuario

Esta guia es para personas **usando** la aplicacion pptx-viewer para trabajar con presentaciones PowerPoint (`.pptx`) en el navegador. Cubre la visualizacion, edicion, presentacion, exportacion y colaboracion - sin necesidad de codigo.

::: info Las funciones dependen de como se configure la aplicacion
pptx-viewer es un componente configurable, por lo que los botones y paneles exactos que ve dependen de como el desarrollador haya activado las funciones. La edicion solo esta disponible cuando el componente esta configurado con la edicion habilitada (`canEdit`).
:::

## Lo que puede hacer

| Tarea          | Que significa                                                                           | Pagina                                  |
| -------------- | --------------------------------------------------------------------------------------- | --------------------------------------- |
| **Visualizar** | Abrir un archivo `.pptx` y navegar por sus diapositivas, notas y medios.                | [Visualizacion](/es/user/viewing)       |
| **Editar**     | Anadir, mover, redimensionar y reformatear elementos.                                   | [Edicion](/es/user/editing)             |
| **Presentar**  | Ejecutar una presentacion de pantalla completa con animaciones y vista del presentador. | [Presentacion](/es/user/presenting)     |
| **Exportar**   | Guardar como PNG, JPEG, SVG, PDF, GIF, video o `.pptx`.                                 | [Exportacion](/es/user/exporting)       |
| **Colaborar**  | Coeditar una presentacion en tiempo real con cursores en vivo.                          | [Colaboracion](/es/user/collaboration)  |
| **Atajos**     | Acelerar la navegacion y edicion con el teclado.                                        | [Atajos de teclado](/es/user/shortcuts) |

## Las partes principales de la pantalla

- **Barra de herramientas** (arriba) - Una cinta con pestanas: Archivo, Inicio, Insertar, Texto, Dibujar, Organizar, Diseno, Transiciones, Animaciones, Presentacion, Revisar, Vista y Ayuda.
- **Panel de diapositivas** (izquierda) - Una tira desplazable de miniaturas.
- **Lienzo de diapositivas** (centro) - El area grande de edicion/visualizacion.
- **Panel inspector** (derecha) - Un panel de propiedades contextual.
- **Panel de notas** (debajo del lienzo) - Un editor para las notas del presentador.
- **Barra de estado** (abajo) - Muestra controles de zoom, numero de diapositiva actual y estado de guardado.
