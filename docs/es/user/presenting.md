# Presentar

El modo de presentacion convierte el visualizador en una presentacion de pantalla completa que reproduce sus transiciones y animaciones, con vista del presentador, cronometro y herramientas de anotacion en vivo.

## Iniciar una presentacion

Inicie desde la pestana **Presentacion** de la barra de herramientas. La diapositiva actual se expande para llenar la pantalla.

::: tip
Una barra de herramientas flotante se encuentra en la parte inferior de la pantalla. Se **oculta automaticamente** despues de unos segundos y reaparece cuando mueve el raton.
:::

## Navegar durante una presentacion

| Para...                                       | Hacer esto                                                           |
| --------------------------------------------- | -------------------------------------------------------------------- |
| Ir a la diapositiva / animacion **siguiente** | Hacer clic, o presionar **Flecha derecha**, **Av Pag** o **Espacio** |
| Ir a la diapositiva **anterior**              | Presionar **Flecha izquierda** o **Re Pag**                          |
| **Salir** de la presentacion                  | Presionar **Escape**                                                 |

## Transiciones y animaciones

Cuando se mueve entre diapositivas, la **transicion** asignada a cada diapositiva se reproduce automaticamente, incluidas las transiciones **morph**.

## Vista del presentador

La vista del presentador divide la pantalla para mostrarle informacion que el publico no ve: notas del presentador, vista previa de la siguiente diapositiva y cronometro transcurrido.

Activela durante una presentacion presionando **N**.

## Anotaciones en vivo

| Herramienta           | Atajo        |
| --------------------- | ------------ |
| Puntero laser         | **L**        |
| Boligrafo             | **P**        |
| Borrador              | **E**        |
| Mostrar/ocultar barra | **Ctrl + M** |

## Salir

Presione **Escape** en cualquier momento para terminar la presentacion.
