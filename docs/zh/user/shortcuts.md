# 键盘快捷键 {#keyboard-shortcuts}

macOS 中，请将下文的 **Ctrl** 替换为 **Cmd**。

::: info 快捷键随上下文生效
编辑快捷键只在编辑模式中启用。在文本框或表格单元格中输入，或使用“绘图”工具时，编辑快捷键会暂停，将按键交给文本输入。放映快捷键只在放映时生效，但用于开始放映的 **F5** / **Shift+F5** 除外。**Escape** 始终可用。
:::

::: tip 应用内参考
通过**帮助 > 键盘快捷键**，或 **“...”** 菜单中的**键盘快捷键**，可以打开简明列表。
:::

## 编辑 {#editing}

编辑模式中，且未在元素内输入文本时生效。

| 操作                         | 快捷键                         |
| ---------------------------- | ------------------------------ |
| 撤销                         | **Ctrl+Z**                     |
| 重做                         | **Ctrl+Shift+Z** 或 **Ctrl+Y** |
| 复制选中元素                 | **Ctrl+C**                     |
| 剪切选中元素                 | **Ctrl+X**                     |
| 粘贴元素                     | **Ctrl+V**                     |
| 创建选中元素的副本           | **Ctrl+D**                     |
| 删除选中元素                 | **Delete** 或 **Backspace**    |
| 选中当前页的全部元素         | **Ctrl+A**                     |
| 微调选中元素                 | **方向键**                     |
| 大幅微调选中元素             | **Shift+方向键**               |
| 组合选中元素                 | **Ctrl+G**                     |
| 取消组合                     | **Ctrl+Shift+G**               |
| 打开或关闭查找替换           | **Ctrl+F**                     |
| 打开或关闭快捷键面板         | **?** 或 **Ctrl+/**            |
| 取消选择、关闭菜单或停止编辑 | **Escape**                     |

**Ctrl+F** 是例外，即使光标正在元素中输入，也仍可调用查找，与 PowerPoint 的行为一致。

## 文本编辑 {#text-editing}

在元素内输入时使用。

| 操作         | 快捷键         |
| ------------ | -------------- |
| 确认文本编辑 | **Ctrl+Enter** |
| 取消文本编辑 | **Escape**     |

## 导航与视图 {#navigation-and-view}

| 操作                       | 快捷键            |
| -------------------------- | ----------------- |
| 上一张幻灯片（未选中元素） | **左方向键**      |
| 下一张幻灯片（未选中元素） | **右方向键**      |
| 放大或缩小画布             | **Ctrl+鼠标滚轮** |

状态栏也提供放大、缩小和适应窗口按钮。

::: tip 提示
编辑模式下，选中元素时方向键用于微调位置，未选中元素时用于切换幻灯片。
:::

## 幻灯片浏览视图 {#slide-sorter}

浏览视图浮层打开时生效。

| 操作                       | 快捷键                      |
| -------------------------- | --------------------------- |
| 复制选中幻灯片             | **Ctrl+C**                  |
| 粘贴幻灯片                 | **Ctrl+V**                  |
| 创建选中幻灯片的副本       | **Ctrl+D**                  |
| 选择全部幻灯片             | **Ctrl+A**                  |
| 删除选中幻灯片             | **Delete** 或 **Backspace** |
| 放大 / 缩小缩略图          | **Ctrl +** / **Ctrl -**     |
| 先收起选择，再关闭浏览视图 | **Escape**                  |

::: info 各组件的浏览视图支持范围不同
五个组件均支持 **Escape**、**Delete** 和 **Ctrl+D**。幻灯片剪贴板（**Ctrl+C** / **Ctrl+V**）、**Ctrl+A** 和缩略图缩放快捷键需要支持多选和缩放的浏览视图，目前仅 React 提供。其他组件会将这些组合键交还给浏览器，而不是静默吞掉。
:::

## 幻灯片放映 {#slideshow}

在组件内任意位置都可以通过快捷键开始放映，包括正在输入文本或处于只读模式时；其他放映快捷键仅在放映期间启用。

| 操作             | 快捷键       |
| ---------------- | ------------ |
| 从头开始放映     | **F5**       |
| 从当前页开始放映 | **Shift+F5** |

::: warning 组件获得焦点时，F5 不再刷新页面
F5 同时是 PowerPoint 的放映键和浏览器的刷新键。只有键盘焦点位于组件内且尚未开始放映时，组件才接管单独的 **F5**。**Ctrl+F5** 和浏览器刷新按钮不受影响。
:::

以下按键与 PowerPoint 的放映快捷键一致。批注工具使用 **Ctrl** 组合键，因为单独的 `N`、`P`、`B`、`W` 和 `E` 用于导航和屏幕控制。

| 操作                   | 快捷键                                                                  |
| ---------------------- | ----------------------------------------------------------------------- |
| 下一页或下一个动画步骤 | **右方向键**、**下方向键**、**Page Down**、**空格**、**Enter** 或 **N** |
| 上一页                 | **左方向键**、**上方向键**、**Page Up**、**Backspace** 或 **P**         |
| 第一页                 | **Home**                                                                |
| 最后一页               | **End**                                                                 |
| 跳转到指定页           | 输入页码后按 **Enter**                                                  |
| 开关黑屏               | **B** 或 **.**                                                          |
| 开关白屏               | **W** 或 **,**                                                          |
| 普通箭头指针           | **Ctrl+A**                                                              |
| 激光笔                 | **Ctrl+L**                                                              |
| 画笔                   | **Ctrl+P**                                                              |
| 橡皮擦                 | **Ctrl+E**                                                              |
| 清除当前页全部批注     | **E**                                                                   |
| 显示或隐藏墨迹         | **Ctrl+M**                                                              |
| 显示或隐藏放映工具栏   | **Ctrl+H**                                                              |
| 显示所有幻灯片         | **Ctrl+S**                                                              |
| 开关实时字幕           | **J**                                                                   |
| 放映上下文菜单         | **Shift+F10** 或 **菜单键**                                             |
| 结束放映               | **Escape** 或 **-**                                                     |

::: info 界面控制快捷键的支持范围
**Ctrl+H**（隐藏放映工具栏）和 **Ctrl+S**（显示所有幻灯片）由共享的放映按键映射识别，五个组件均支持。
:::

荧光笔没有键盘快捷键，请使用放映工具栏。演讲者视图也通过工具栏切换，没有独立快捷键。批注工具和演讲者视图的用法见[放映](/zh/user/presenting)。
