# 查看演示文稿 {#viewing-presentations}

本页介绍阅读演示文稿时的操作，包括切换幻灯片、缩放、隐藏页和演讲者备注。首次打开文件的方法见[打开文件](/zh/user/#opening-a-file)。

加载后，当前幻灯片显示在中央的**幻灯片画布**中，左侧**幻灯片面板**显示缩略图列表。

![已加载演示文稿的画布](/user-guide/viewing-slide-canvas.jpg)

图表、表格、形状、SmartArt 和媒体均作为实际内容渲染，你可以像普通网页一样选择和复制幻灯片中的文本。

![幻灯片中的图表](/docs-shots/chart-slide.jpg)

## 切换幻灯片 {#navigating-slides}

可以通过以下方式切换：

- **幻灯片面板**：点击左侧任意缩略图，直接跳转到对应页面。
- **方向键**：画布未选中元素时，按**左方向键**或**右方向键**切换到上一页或下一页。
- **状态栏**：左下角显示**第 x 张，共 y 张**，方便确认当前位置。

![切换幻灯片](/user-guide/viewing-navigation.gif)

幻灯片面板会在当前页左侧显示彩色高亮条。

::: tip 方向键有两种用途
编辑模式下，方向键用于微调选中元素的位置。只有未选中元素时才会切换幻灯片，可以先按 **Escape** 取消选择。
:::

## 缩放与适应窗口 {#zooming-and-fitting}

缩放控件位于**状态栏**右侧：

| 控件                 | 作用                                                   |
| -------------------- | ------------------------------------------------------ |
| **缩小**（减号按钮） | 逐级降低缩放比例。                                     |
| **百分比按钮**       | 显示当前缩放比例，点击后让幻灯片**适应可用画布区域**。 |
| **放大**（加号按钮） | 逐级提高缩放比例。                                     |

![状态栏中的缩放控件](/user-guide/viewing-status-bar.jpg)

你也可以：

- 按住 **Ctrl**（macOS 为 Cmd），在画布上滚动鼠标滚轮，以指针位置为中心平滑缩放。
- 使用功能区的**视图 > 适应窗口**。
- 在触控设备上使用双指缩放。

## 视图模式 {#view-modes}

状态栏提供三种视图按钮：

- **普通视图**：显示幻灯片面板、画布和属性面板的标准布局。
- **幻灯片浏览**：以全屏网格显示所有幻灯片。
- **幻灯片放映**：开始全屏放映，详见[放映](/zh/user/presenting)。

### 幻灯片浏览视图 {#the-slide-sorter}

浏览大型演示文稿时，可以使用幻灯片浏览视图查看整体结构：

1. 点击状态栏的**幻灯片浏览**。
2. 浏览网格。如果文稿包含节，幻灯片会按节标题分组。
3. **双击**某页可在普通视图中打开，按 **Escape** 可关闭浏览视图。

在此视图中还可以：

- 编辑模式下拖动幻灯片调整顺序。
- 点击选择，按住 **Shift** 点击选择一个范围，或右键进行复制、隐藏和删除等操作，详见[管理幻灯片](/zh/user/editing#managing-slides)。
- 使用底部工具栏滑块调整缩略图大小，或按 **Ctrl +** / **Ctrl -**。

## 隐藏幻灯片 {#hidden-slides}

隐藏页仍保留在文件中，但放映时会跳过。

- 幻灯片面板和浏览视图中，隐藏页会变暗，并带有斜线纹理和隐藏图标。
- 仍可正常打开、阅读和编辑隐藏页。
- 编辑模式下，在浏览视图中右键选择幻灯片，点击**隐藏幻灯片**或**显示幻灯片**即可切换。

## 阅读演讲者备注 {#reading-speaker-notes}

1. 点击状态栏的**备注**按钮，打开画布下方的备注面板。
2. 面板显示当前幻灯片的备注，内容较长时可以滚动。
3. 再次点击**备注**关闭面板。

放映时，**演讲者视图**只向你显示备注，观众不会看到，详见[演讲者视图](/zh/user/presenting#presenter-view)。
