# Tastaturkurzbefehle

Dies sind die integrierten Tastaturkurzbefehle des Viewers/Editors. Auf macOS verwenden Sie **Cmd** uberall, wo **Ctrl** angegeben ist.

::: info Kurzbefehle sind kontextsensitiv
Welche Kurzbefehle aktiv sind, hangt vom Modus ab. Bearbeitungskurzbefehle funktionieren nur im **Bearbeitungsmodus** und werden unterdruckt, wahrend Sie in ein Textfeld tippen.
:::

## Bearbeitung

Verfugbar im Bearbeitungsmodus, wenn Sie nicht in ein Element tippen.

| Aktion                                                      | Kurzbefehl                             |
| ----------------------------------------------------------- | -------------------------------------- |
| Ruckgangig                                                  | **Strg + Z**                           |
| Wiederholen                                                 | **Strg + Umsch + Z** oder **Strg + Y** |
| Ausgewahltes Element kopieren                               | **Strg + C**                           |
| Ausgewahltes Element ausschneiden                           | **Strg + X**                           |
| Element einfugen                                            | **Strg + V**                           |
| Ausgewahltes Element duplizieren                            | **Strg + D**                           |
| Ausgewahltes Element loschen                                | **Entf** oder **Rucktaste**            |
| Alle Elemente auswahlen                                     | **Strg + A**                           |
| Ausgewahltes Element leicht verschieben                     | **Pfeiltasten**                        |
| Ausgewahltes Element weit verschieben                       | **Umsch + Pfeiltasten**                |
| Inline-Textbearbeitung bestatigen                           | **Strg + Eingabe**                     |
| Bearbeitung abbrechen / Menus schliessen / Auswahl aufheben | **Esc**                                |

## Navigation

| Aktion                                                 | Kurzbefehl            |
| ------------------------------------------------------ | --------------------- |
| Vorherige Folie (Bearbeitungsmodus, nichts ausgewahlt) | **Pfeiltaste links**  |
| Nachste Folie (Bearbeitungsmodus, nichts ausgewahlt)   | **Pfeiltaste rechts** |

## Prasentation

| Aktion                                   | Kurzbefehl                                                   |
| ---------------------------------------- | ------------------------------------------------------------ |
| Nachste Folie / Animation                | Klick, **Pfeiltaste rechts**, **Bild abwarts** oder **Leer** |
| Vorherige Folie                          | **Pfeiltaste links** oder **Bild aufwarts**                  |
| Diashow beenden                          | **Esc**                                                      |
| Referentenansicht umschalten             | **N**                                                        |
| Laserpointer aktivieren                  | **L**                                                        |
| Stift aktivieren                         | **P**                                                        |
| Radierer aktivieren                      | **E**                                                        |
| Diashow-Symbolleiste anzeigen/ausblenden | **Strg + M**                                                 |
