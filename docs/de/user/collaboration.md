# Zusammenarbeit

pptx-viewer unterstutzt **Echtzeit-Co-Editing**: Mehrere Personen konnen dieselbe Prasentation gleichzeitig offnen und die Anderungen der anderen live sehen.

::: info Optional und vom Entwickler konfiguriert
Zusammenarbeit ist eine optionale Funktion. Sie funktioniert nur, wenn die App fur die Verbindung mit einer Zusammenarbeitssitzung (einem "Raum" auf einem Zusammenarbeitsserver) konfiguriert wurde.
:::

## Wie Zusammenarbeit sich anfuhlt

- **Live-Anwesenheit** - Eine Leiste farbcodierter **Avatare** zeigt, wer sich in der Sitzung befindet.
- **Remote-Cursor** - Sie konnen die Cursor anderer Personen auf der Folienleinwand sehen.
- **Gleichzeitige Bearbeitungen** - Wenn jemand eine Form verschiebt oder Text bearbeitet, sehen Sie die Aktualisierung in nahezu Echtzeit.
- **Verbindungsstatus** - Ein Indikator zeigt, ob Sie **verbunden**, **synchronisierend** oder **getrennt** sind.

## Einer Sitzung beitreten

- Die App **tritt automatisch bei**, wenn sie geladen wird.
- Die App bietet einen **Teilen**-Dialog, wo Sie einen **Raumnamen** und eine **Serveradresse** eingeben.
- Sie offnen einen **Link**, der bereits die Raumdetails enthalt.

::: tip Kein Server? Peer-to-Peer-Modus
In den Teilen- und Ubertragen-Dialogen konnen Sie die **Serveradresse leer lassen**, um eine **Peer-to-Peer**-Sitzung zu starten.
:::

## Tipps fur reibungslose Zusammenarbeit

- Kommunizieren Sie, an welcher Folie jede Person arbeitet.
- Behalten Sie den **Verbindungsstatus** im Auge - wenn getrennt, werden Ihre jungsten Anderungen moglicherweise nicht synchronisiert.
- Kommentare sind eine gute Moglichkeit, asynchrones Feedback zu hinterlassen.
