# Benutzerhandbuch

Dieser Leitfaden richtet sich an Menschen, die die pptx-viewer-App zum Arbeiten mit PowerPoint-Prasentation (`.pptx`) im Browser **verwenden**. Er deckt Anzeigen, Bearbeiten, Prasentieren, Exportieren und Zusammenarbeiten ab - kein Code erforderlich.

::: info Funktionen hangen von der App-Konfiguration ab
pptx-viewer ist eine konfigurierbare Komponente, daher hangen die genauen Schaltflachen und Panels, die Sie sehen, davon ab, wie der Entwickler Funktionen aktiviert hat. Bearbeitung ist nur verfugbar, wenn die Komponente mit aktivierter Bearbeitung konfiguriert ist (`canEdit`).
:::

## Was Sie tun konnen

| Aufgabe              | Was das bedeutet                                                        | Seite                                     |
| -------------------- | ----------------------------------------------------------------------- | ----------------------------------------- |
| **Anzeigen**         | Eine `.pptx`-Datei offnen und durch Folien, Notizen und Medien browsen. | [Anzeigen](/de/user/viewing)              |
| **Bearbeiten**       | Elemente hinzufugen, verschieben, skalieren und neu formatieren.        | [Bearbeiten](/de/user/editing)            |
| **Prasentieren**     | Eine Vollbild-Diashow mit Animationen und Referentenansicht starten.    | [Prasentieren](/de/user/presenting)       |
| **Exportieren**      | Als PNG, JPEG, SVG, PDF, GIF, Video oder `.pptx` speichern.             | [Exportieren](/de/user/exporting)         |
| **Zusammenarbeiten** | Eine Prasentation in Echtzeit mit Live-Cursorn gemeinsam bearbeiten.    | [Zusammenarbeit](/de/user/collaboration)  |
| **Kurzbefehle**      | Navigation und Bearbeitung mit der Tastatur beschleunigen.              | [Tastaturkurzbefehle](/de/user/shortcuts) |

## Die Hauptbereiche des Bildschirms

- **Symbolleiste** (oben) - Ein Menüband mit Registerkarten: Datei, Start, Einfugen, Text, Zeichnen, Anordnen, Design, Ubergange, Animationen, Bildschirmprasentation, Uberpruefen, Ansicht und Hilfe.
- **Folienbereich** (links) - Ein scrollbarer Streifen mit Miniaturansichten.
- **Folienleinwand** (Mitte) - Der grosse Bearbeitungs-/Anzeigebereich.
- **Inspektionsbereich** (rechts) - Ein kontextsensitives Eigenschaftsfenster.
- **Notizbereich** (unterhalb der Leinwand) - Ein Editor fur Referentennotizen.
- **Statusleiste** (unten) - Zeigt Zoomsteuerelemente, aktuelle Foliennummer und Speicherstatus an.
