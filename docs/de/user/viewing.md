# Prasentation anzeigen

Diese Seite behandelt das Lesen einer Prasentation: Eine Datei offnen, zwischen Folien navigieren, zoomen und Referentennotizen anzeigen.

## Eine Datei offnen

Wie eine Prasentation geladen wird, hangt von der App ab:

- Viele Apps laden automatisch eine Prasentation (z. B. von einem Link oder Server).
- Apps, die die Dateiauswahl erlauben, bieten in der Regel eine **Offnen**-Aktion auf der **Datei**-Registerkarte der Symbolleiste oder einen Drag-and-Drop-Bereich.

::: info Verschlusselte Dateien
Wenn die Datei passwortgeschutzt ist, zeigt die App einen Passwort-Dialog. Geben Sie das Passwort ein, um die Prasentation zu entschlusseln und zu offnen.
:::

## Zwischen Folien navigieren

- **Folienbereich** - Klicken Sie auf eine beliebige Miniaturansicht links, um direkt zu dieser Folie zu springen.
- **Pfeiltasten** - Wenn nichts auf der Leinwand ausgewahlt ist, drucken Sie **Pfeiltaste links** / **Pfeiltaste rechts**, um zur vorherigen / nachsten Folie zu wechseln.

::: tip Ausgeblendete Folien
Als ausgeblendet markierte Folien erscheinen im Folienbereich gedimmt und werden wahrend einer Diashow ubersprungen, konnen aber trotzdem angezeigt und bearbeitet werden.
:::

## Zoomen und Anpassen

Verwenden Sie die Zoomsteuerelemente in der **Statusleiste** (oder der **Ansicht**-Symbolleistensregisterkarte):

- **Vergrossern** - Erhohen Sie den Zoomgrad, um Details zu sehen.
- **Verkleinern** - Verringern Sie, um mehr von der Folie zu sehen.
- **Anpassen** - Passen Sie an, sodass die gesamte Folie in das verfugbare Fenster passt.

## Der Foliensortierer

Uber die **Ansicht**-Registerkarte oder die Statusleiste zuganglich. Zeigt alle Folien als Miniaturansicht-Raster an und erleichtert die Neuanordnung.

## Referentennotizen

Klicken Sie in das **Notizfeld** unterhalb der Leinwand, um die Referentennotizen der aktuellen Folie zu lesen oder zu bearbeiten.
