# Folien bearbeiten

::: warning Bearbeitung muss aktiviert sein
Bearbeitung ist nur verfugbar, wenn die App mit aktiviertem Bearbeitungsmodus konfiguriert ist (der Entwickler setzt `canEdit`). Wenn die Symbolleiste nur Anzeigeoptionen zeigt, befinden Sie sich im schreibgeschutzten Modus.
:::

## Elemente auswahlen und verschieben

Klicken Sie auf ein beliebiges Element auf der Folie, um es auszuwahlen. Ein ausgewahltes Element zeigt Anfasser (kleine Quadrate an den Ecken und in der Mitte der Kanten).

- **Verschieben** - ziehen Sie das ausgewahlte Element an eine neue Position.
- **Skalieren** - ziehen Sie einen Ecken- oder Kantengriff, um die Grosse zu andern.
- **Drehen** - ziehen Sie den Rotationsgriff (uber dem Element).
- **Mehrfachauswahl** - halten Sie **Umsch** gedruckt und klicken Sie, um mehrere Elemente auszuwahlen.

## Elemente hinzufugen

Verwenden Sie die Registerkarte **Einfugen** der Symbolleiste:

- **Text** - fugen Sie ein Textfeld ein. Doppelklicken Sie, um den Text zu bearbeiten.
- **Formen** - zeichnen Sie Rechtecke, Ellipsen, Pfeile und uber 187 voreingestellte Formen.
- **Bild** - fugen Sie aus einer lokalen Datei oder URL ein.
- **Tabelle** - fugen Sie eine Tabelle mit gewahlter Zeilen- und Spaltenzahl ein.
- **Diagramm** - fugen Sie ein Diagramm ein; ziehen Sie Balken oder Punkte direkt auf der Folie, um Werte zu andern, oder bearbeiten Sie die Daten im Inspektor.

## Mit dem Inspektor formatieren

Das **Inspektionsfeld** (rechts) ist kontextsensitiv.

## Ruckgangig und Wiederholen

- **Ruckgangig** - **Strg/Cmd + Z**
- **Wiederholen** - **Strg/Cmd + Umsch + Z** oder **Strg/Cmd + Y**

## Folien verwalten

Arbeiten Sie mit Folien aus dem **Folienbereich** oder dem Kontextmenu:

- **Folie hinzufugen** - neue leere Folie einfugen.
- **Duplizieren** - vorhandene Folie kopieren.
- **Loschen** - ausgewahlte Folie entfernen.
- **Neuanordnen** - Miniaturansichten im Bereich ziehen.

## Suchen und Ersetzen

Offnen Sie **Suchen und Ersetzen** von der Registerkarte **Uberpruefen**, um Text uber **alle** Folien gleichzeitig zu suchen.

## Kommentare

Verwenden Sie die Registerkarte **Uberpruefen**, um Kommentare zu Folien oder Elementen hinzuzufugen, zu antworten, zu losen oder zu loschen.
