# Exportieren

Sie konnen die aktuelle Folie oder die gesamte Prasentation in verschiedenen Formaten exportieren. Exportaktionen befinden sich auf der **Datei**-Registerkarte der Symbolleiste.

## Verfugbare Formate

| Format                 | Was Sie erhalten                                     | Umfang         |
| ---------------------- | ---------------------------------------------------- | -------------- |
| **PNG-Bild**           | Ein Rasterbild der aktuellen Folie.                  | Aktuelle Folie |
| **Als Bild kopieren**  | Kopiert die aktuelle Folie in die Zwischenablage.    | Aktuelle Folie |
| **PDF**                | Ein mehrseitiges PDF, eine Folie pro Seite.          | Gesamtes Deck  |
| **GIF**                | Ein animiertes GIF, das durch die Folien blattert.   | Gesamtes Deck  |
| **Video**              | Ein `.webm`-Video, das durch die Folien spielt.      | Gesamtes Deck  |
| **Als PPTX speichern** | Eine Standard-PowerPoint-Datei mit Ihren Anderungen. | Gesamtes Deck  |
| **Als PPSX speichern** | Eine PowerPoint-Diashow-Datei.                       | Gesamtes Deck  |

::: tip SVG-Export
Ein vektorbasierter **SVG**-Exportpfad ist ebenfalls verfugbar. Da er vektorbasiert ist, vermeidet er die Rasterisierungsgrenzen.
:::

## Exportieren

1. Offnen Sie die **Datei**-Registerkarte der Symbolleiste.
2. Wahlen Sie **Exportieren** und wahlen Sie ein Format.
3. Bei Formaten fur das gesamte Deck (PDF, GIF, Video) erscheint ein **Fortschrittsdialog**.
4. Die fertige Datei wird automatisch heruntergeladen.

## Treuegrenzen

::: warning Raster-Exporte sind eine Naherung
PNG, JPEG, PDF, GIF und Video-Exporte rastern das HTML/CSS mithilfe von `html2canvas`. Einige CSS-Funktionen werden nicht vollstandig unterstutzt. Fur die genaueste Ausgabe bevorzugen Sie den **SVG**-Export.
:::
