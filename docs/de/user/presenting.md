# Prasentieren

Der Prasentationsmodus verwandelt den Viewer in eine Vollbild-Diashow, die Ihre Ubergange und Animationen abspielt, mit Referentenansicht, Zeitgeber und Live-Annotationswerkzeugen.

## Eine Diashow starten

Starten Sie uber die **Bildschirmprasentation**-Registerkarte der Symbolleiste. Die aktuelle Folie vergrossert sich auf den Vollbildschirm.

::: tip
Eine schwebende Symbolleiste befindet sich unten auf dem Bildschirm. Sie **blendet sich automatisch aus** nach einigen Sekunden ohne Mausbewegung und erscheint wieder, wenn Sie die Maus bewegen.
:::

## Wahrend einer Diashow navigieren

| Um...                                       | Tun Sie dies                                                                |
| ------------------------------------------- | --------------------------------------------------------------------------- |
| Zur **nachsten** Folie / Animation zu gehen | Klicken, oder **Pfeiltaste rechts**, **Bild abwarts** oder **Leer** drucken |
| Zur **vorherigen** Folie zu gehen           | **Pfeiltaste links** oder **Bild aufwarts** drucken                         |
| Die Diashow zu **beenden**                  | **Esc** drucken                                                             |

## Ubergange und Animationen

Beim Wechsel zwischen Folien wird der jeder Folie zugewiesene **Ubergang** automatisch abgespielt, einschliesslich **Morph**-Ubergangen.

## Referentenansicht

Die Referentenansicht teilt den Bildschirm, um Informationen anzuzeigen, die das Publikum nicht sieht: Referentennotizen, Vorschau der nachsten Folie und abgelaufener Zeitgeber.

Schalten Sie sie wahrend einer Diashow durch Drucken von **N** ein.

## Live-Annotationen

| Werkzeug             | Kurzbefehl   |
| -------------------- | ------------ |
| Laserpointer         | **L**        |
| Stift                | **P**        |
| Radierer             | **E**        |
| Symbolleiste ein/aus | **Strg + M** |

## Beenden

Drucken Sie zu jeder Zeit **Esc**, um die Diashow zu beenden.
