# Visualiser les presentations

Cette page couvre la lecture d'une presentation : ouverture d'un fichier, navigation entre les diapositives, zoom et affichage des notes du presentateur.

## Ouverture d'un fichier

La facon dont une presentation est chargee depend de l'application :

- Beaucoup d'applications chargent automatiquement une presentation (par exemple, depuis un lien ou un serveur).
- Les applications qui vous permettent de choisir un fichier proposent generalement une action **Ouvrir** dans l'onglet **Fichier** de la barre d'outils, ou une zone de glisser-deposer.

::: info Fichiers chiffres
Si le fichier est protege par un mot de passe, l'application affiche une boite de dialogue de mot de passe. Saisissez le mot de passe pour dechiffrer et ouvrir la presentation.
:::

## Navigation entre les diapositives

- **Panneau de diapositives** - Cliquez sur n'importe quelle vignette a gauche pour acceder directement a cette diapositive.
- **Touches fleches** - Avec rien de selectionne sur le canevas, appuyez sur **Fleche gauche** / **Fleche droite** pour passer a la diapositive precedente / suivante.

::: tip Diapositives masquees
Les diapositives marquees comme masquees sont estompees dans le panneau et sautees pendant un diaporama, mais vous pouvez toujours les visualiser et les editer.
:::

## Zoom et ajustement

Utilisez les controles de zoom dans la **barre d'etat** (ou l'onglet **Affichage**) :

- **Zoom avant** - augmentez le niveau de zoom pour voir les details.
- **Zoom arriere** - diminuez pour voir plus de la diapositive.
- **Ajuster** - ajustez pour que la diapositive entiere rentre dans la fenetre disponible.

## Le trieur de diapositives

Acces depuis l'onglet **Affichage** ou la barre d'etat. Il affiche toutes les diapositives sous forme de grille de vignettes, facilitant la reorganisation de grandes presentatinos.

## Notes du presentateur

Cliquez sur le **panneau de notes** sous le canevas pour lire ou modifier les notes du presentateur de la diapositive actuelle.
