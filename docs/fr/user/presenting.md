# Presenter

Le mode presentation transforme le visualiseur en un diaporama plein ecran qui joue vos transitions et animations, avec une vue du presentateur, un minuteur et des outils d'annotation en direct.

## Demarrer un diaporama

Commencez depuis l'onglet **Diaporama** de la barre d'outils. La diapositive actuelle s'elargit pour remplir l'ecran.

::: tip
Une barre d'outils flottante se trouve en bas de l'ecran. Elle **se masque automatiquement** apres quelques secondes et reapparait quand vous bougez la souris.
:::

## Naviguer pendant un diaporama

| Pour...                                         | Faites ceci                                                           |
| ----------------------------------------------- | --------------------------------------------------------------------- |
| Aller a la diapositive / animation **suivante** | Cliquez, ou appuyez sur **Fleche droite**, **Page Bas** ou **Espace** |
| Aller a la diapositive **precedente**           | Appuyez sur **Fleche gauche** ou **Page Haut**                        |
| **Quitter** le diaporama                        | Appuyez sur **Echap**                                                 |

## Transitions et animations

Lorsque vous passez d'une diapositive a l'autre, la **transition** assignee a chaque diapositive se joue automatiquement, y compris les transitions **morph** qui animent les elements correspondants.

## Vue du presentateur

La vue du presentateur divise l'ecran pour vous montrer des informations que le public ne voit pas : notes du presentateur, apercu de la diapositive suivante et minuteur ecoule.

Activez-la pendant un diaporama en appuyant sur **N**.

## Annotations en direct

| Outil                     | Raccourci    |
| ------------------------- | ------------ |
| Pointeur laser            | **L**        |
| Stylo                     | **P**        |
| Gomme                     | **E**        |
| Afficher/masquer la barre | **Ctrl + M** |

## Quitter

Appuyez sur **Echap** a tout moment pour terminer le diaporama.
