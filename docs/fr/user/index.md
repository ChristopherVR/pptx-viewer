# Guide utilisateur

Ce guide est destine aux personnes **utilisant** l'application pptx-viewer pour travailler avec des presentations PowerPoint (`.pptx`) dans le navigateur. Il couvre la visualisation, l'edition, la presentation, l'exportation et la collaboration - aucun code requis.

Si vous etes un developpeur integrant le visualiseur dans votre propre application, consultez plutot la [documentation React](/react/).

::: info Les fonctionnalites dependent de la configuration de l'application
pptx-viewer est un composant configurable, donc les boutons et panneaux exacts que vous voyez dependent de la facon dont le developpeur a configure les fonctionnalites. L'edition n'est disponible que lorsque le composant est configure avec l'edition activee (`canEdit`).
:::

## Les principales parties de l'ecran

- **Barre d'outils** (en haut) - Un ruban a onglets avec les sections Fichier, Accueil, Insertion, Texte, Dessin, Organiser, Creation, Transitions, Animations, Diaporama, Revision, Affichage et Aide.
- **Panneau de diapositives** (gauche) - Une bande defilante de vignettes. Cliquez pour acceder a une diapositive ; faites glisser pour reordonner.
- **Canevas de diapositives** (centre) - La grande zone d'edition/visualisation.
- **Panneau d'inspection** (droite) - Un panneau de proprietes contextuel.
- **Panneau de notes** (sous le canevas) - Un editeur pour les notes du presentateur.
- **Barre d'etat** (bas) - Affiche les controles de zoom, le numero de diapositive actuel et l'etat de sauvegarde.
