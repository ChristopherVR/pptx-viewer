# Raccourcis clavier

Ce sont les raccourcis clavier integres au visualiseur/editeur. Sur macOS, utilisez **Cmd** partout ou **Ctrl** est indique.

::: info Les raccourcis sont sensibles au contexte
Les raccourcis actifs dependent du mode dans lequel vous etes et de ce que vous faites. Les raccourcis d'edition fonctionnent uniquement en **mode edition** et sont supprimes pendant que vous tapez dans une zone de texte.
:::

## Edition

Disponible en mode edition, lorsque vous ne tapez pas dans un element.

| Action                                                | Raccourci                          |
| ----------------------------------------------------- | ---------------------------------- |
| Annuler                                               | **Ctrl + Z**                       |
| Retablir                                              | **Ctrl + Maj + Z** ou **Ctrl + Y** |
| Copier l'element selectionne                          | **Ctrl + C**                       |
| Couper l'element selectionne                          | **Ctrl + X**                       |
| Coller l'element                                      | **Ctrl + V**                       |
| Dupliquer l'element selectionne                       | **Ctrl + D**                       |
| Supprimer l'element selectionne                       | **Suppr** ou **Retour arriere**    |
| Selectionner tous les elements                        | **Ctrl + A**                       |
| Deplacer legerement l'element selectionne             | **Fleches directionnelles**        |
| Deplacer largement l'element selectionne              | **Maj + Fleches directionnelles**  |
| Valider l'edition de texte en ligne                   | **Ctrl + Entree**                  |
| Annuler l'edition / fermer les menus / deselectionner | **Echap**                          |

## Navigation

| Action                                                  | Raccourci         |
| ------------------------------------------------------- | ----------------- |
| Diapositive precedente (mode edition, rien selectionne) | **Fleche gauche** |
| Diapositive suivante (mode edition, rien selectionne)   | **Fleche droite** |

## Presentation

| Action                                 | Raccourci                                           |
| -------------------------------------- | --------------------------------------------------- |
| Diapositive / animation suivante       | Clic, **Fleche droite**, **Page Bas** ou **Espace** |
| Diapositive precedente                 | **Fleche gauche** ou **Page Haut**                  |
| Quitter le diaporama                   | **Echap**                                           |
| Basculer la vue presentateur           | **N**                                               |
| Activer le pointeur laser              | **L**                                               |
| Activer le stylo                       | **P**                                               |
| Activer la gomme                       | **E**                                               |
| Afficher/masquer la barre de diaporama | **Ctrl + M**                                        |
